Subsets of Cormorant Garamond (400) and Manrope (500) in WOFF format, used only
to render Open Graph preview images (`src/app/[locale]/opengraph-image.tsx`).
Both fonts are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Subsets were downloaded from Google Fonts with
the `text=` parameter; they contain Latin, Cyrillic (including Kyrgyz ң ө ү)
and the Uzbek ʻ ʼ letters.
